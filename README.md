# CS4210FinalProject

Dark Pattern Detector is an AI-powered Chrome extension designed to identify deceptive UI designs, specifically "Dark Patterns" like Scarcity, Social Proof, and Urgency. The system utilizes a DistilBERT-base-uncased architecture, chosen for its ability to maintain high performance while offering the low latency required for real-time browser interface. The project backend is powered by a Flask API that processes DOM elements caputred by a Manifest V3 extension, highlighting suspicious text with a red border and providing users with AI-driven alerts. To ensure robust detection across modern e-commerce sites like Amazon, the training data was supplemented with a custom Selenium scraper and optimized over 10 epochs to mitigate class imbalance and improve the model's ability to generalize to new data.
